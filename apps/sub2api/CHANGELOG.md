# 更新记录

这里只记录飞牛打包版本的变化，上游 Sub2API 版本单独列出。
历史材料没有独立发布日期，不补写日期，也不以源码检查代替设备验收。
安装、数据保留与升级前置条件见 [README](README.md)。

## 1.20

上游版本：`0.2.18 → 0.2.19`（[上游发布说明](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.19)）。

- 更新主服务镜像，锁定多架构索引、amd64/arm64 平台摘要，以及上游附注标签与源码提交。
- 上游新增按操作与资源范围授权的管理员 API Key、OpenAI / Composite 分组可选的按实际出图张数计费，以及 GPT-6.1 Terra 支持。按张计费默认关闭，仅作用于专用图片端点。
- 核对上游 Dockerfile、Compose、入口脚本、自动安装校验与许可证均未变化；保持安装/升级脚本、端口 `18081`、数据挂载、运行凭据和 PostgreSQL/Redis 镜像摘要不变。
- 包版本与锁文件断言同步更新，并增加 `fpk_version` 必须与飞牛包版本一致的检查。

启动时会自动执行迁移 247（管理员 API Key 表）和 248（分组按张计费字段）。
升级前保存同一时间点的数据库与应用数据备份，回退必须恢复匹配备份，不能只切回旧镜像。
Gemini 默认模型目录移除 2.x 系列；仍需使用时请显式配置账号白名单或模型映射。
本版尚未执行目标 NAS 的实机升级、冷启动与业务验收；旧版 G480 升级记录不替代本版验收。

## 1.19

上游版本：`0.2.17 → 0.2.18`。

- 更新主服务镜像，继续锁定多架构索引、amd64/arm64 平台摘要与上游源码来源。
- 修正随包 LICENSE 的 LF 字节摘要断言，继续严格逐字节校验，不先改写文本。
- 上游 0.2.18 未改动 Compose 依赖与自动安装变量；端口 `18081`、数据挂载、运行凭据与 PostgreSQL/Redis 镜像摘要均保持不变。
- 生命周期脚本与安装向导未改动，`12–72` 管理员口令范围继续与上游 `8–72` 字节下限兼容。

升级会执行上游迁移 246，把已有 Gemini / Antigravity 分组的生图开关设为开启；
混合（composite）分组不会自动开启该开关，升级后需要生图时要在分组设置中手动打开，否则请求返回 400。
回退时须恢复匹配的数据库与应用数据备份，仅切回旧镜像不会撤销迁移。当前版本实机验收尚未完成。

## 1.18

上游版本：`0.2.11 → 0.2.17`。

- 更新主服务镜像，继续锁定多架构索引、amd64/arm64 平台摘要与上游源码来源。
- 管理员口令范围由包侧 `12–128` 收紧为 `12–72` 个允许的 ASCII 字符，统一向导与安装校验。
- Shell 成为唯一构建和校验实现，PowerShell 入口只负责转发。
- 源 manifest 不再手写 checksum，由 fnpack 生成并在产物中验证；规范包内普通文件权限。
- 保持端口 `18081`、数据挂载、既有凭据与 PostgreSQL/Redis 镜像摘要不变。

升级会执行上游数据库迁移，回退时须恢复匹配的数据库与应用数据备份。
OAuth/SetupToken 账号使用 GPT-5.5 前需检查模型映射；当前版本实机验收尚未完成。

## 1.17

上游版本：`0.2.7 → 0.2.11`。

- 更新主服务镜像，并记录上游标签、源码提交和各平台镜像摘要。
- 保持数据挂载、运行凭据、端口、依赖镜像和升级生命周期不变。
- 以无秘密的 `.keep` 保留空凭据目录，保证新检出仍具备所需挂载目录。

升级前检查上游默认的 API Key 创建限制、余额在途预留及自定义定价转换。
数据库迁移后的回退需要匹配备份，不仅是切回旧镜像。
