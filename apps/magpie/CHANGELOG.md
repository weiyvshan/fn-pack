# 更新记录

这里记录 fnOS 打包侧的变化。以下版本均采用官方 CLI `0.1.1275`，不混用飞牛包版本与上游程序版本。

## 0.1.1275-3

- 修复旧包装层关闭账号发现，导致插件登录成功后账号列表仍为空的问题。
- 移除启动时的 `MAGPIE_NO_ACCOUNTS=1`，也不再在首次初始化时执行 `accounts discovery off`。
- 对旧设置执行一次恢复：将旧版写入的账号发现关闭状态恢复为开启，成功后写入迁移标记。迁移失败时留待下次启动重试；标记存在后保留用户的设置选择。
- 沿用已有配置、凭据、管理密钥和网关端口，保留关闭程序自更新及统计上报的行为。

这次修复不要求用户重新登录插件。现有验证记录来自隔离回归及 FPK 检查，真实应用中心升级与 root 降权分支仍待验收。

## 0.1.1275-2

- 移除 `MAGPIE_ADDR` 环境变量覆盖，恢复网页设置中的网关端口修改。
- 启动、就绪、状态、端口冲突、停止和升级检查改为读取持久化设置中的网关端口；默认仍为 `127.0.0.1:3425`，非法值会使启动明确失败。
- 保留前版的日志权限修复，升级继续沿用配置与管理密钥。

## 0.1.1275-1

- 修复启动横幅含管理密钥时，其他本机账号可读取旧日志的问题。
- 日志目录权限由 `0755` 收紧为 `0700`，日志文件改为 `0600`，每次启动也会收紧已有日志文件的权限。
- 升级保留配置和管理密钥，不自动轮换密钥。

## 0.1.1275

- 首个 fnOS 原生 FPK，采用官方 Linux amd64 静态 CLI，程序摘要与官方发布清单核对。
- 提供网页管理与网关服务，管理端口为 `3430`，网关默认使用 `127.0.0.1:3425`。
- 通过安装向导设置管理密钥，以独立应用身份运行；配置、日志和密钥保存在应用私有目录，升级保留数据。
- 不使用 Docker，不额外引入 Node、Python 或 Go 运行时。
