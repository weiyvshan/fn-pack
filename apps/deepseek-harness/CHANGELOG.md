# Changelog

记录 fnOS 安装包的主要变化；安装包版本与上游 DSH 版本独立。完整技术细节与历史记录可通过 Git 历史追溯。

## Unreleased

## 0.0.23

- 上游从 **DSH 0.2.1-rc.2** 同步至 **0.2.1-rc.4**，锁定官方发布提交 `504a01a9578abc2c6f1fb896b1dc322c9fe24f66`，同步源码树、pnpm 锁文件与 CLI 清单摘要。
- 保留五个 fnOS 兼容补丁及其严格摘要校验；包内 pnpm 11.28.5、Linux system 二进制 0.1.2 与 Node.js 24 依赖不变。
- 校正 Windows 源契约测试中的构建断言，以及第三方声明中的补丁说明。
- 修复构建器在拒绝已有同名 FPK 后，退出清理仍误删该旧产物的问题；新增隔离回归。

## 0.0.22

- 修复后端就绪与认证令牌就绪之间的竞态导致启动失败的问题：后端会先让 HTTP 端点可用、稍后才写浏览器认证令牌，启动脚本现在等待令牌出现，并按网关代理的规则校验令牌文件的权限与属主。

## 0.0.21

- 修复安装或升级后平台自动启动失败的问题：包安装期间数据卷可能短暂只读，启动脚本现在会等待卷恢复可写，不再因日志写入失败而被 `set -e` 中断。
- 修复服务日志不可写时整个脚本被终止的问题：所有写入改用受保护的写法，日志降级到平台捕获的标准错误，不再输出重定向失败噪音。
- 修复启动时把"后端暂时没响应"误判为"后端已退出"的问题：稳定性检查现在区分进程消失与探测超时，繁忙的后端不再被判为退出，连续多次未响应才报告未响应。
- 启动失败时不再销毁仍在正常响应的后端：清理路径会保留健康后端，下一次启动直接复用它，只修复网关代理。
- 平台在后端就绪后中断启动时，改为完成剩余启动步骤而不是中止，避免留下半启动状态。
- 网关代理改为在后端就绪后立即启动，与稳定性窗口并行，就绪后的总耗时相应缩短。
- 修复停止服务只终止单个进程的问题：后端与网关代理现在各自运行在独立的进程组中，停止时按进程组终止，服务派生的子进程不再残留。

## 0.0.20

- 修复插件配置热重载后会话控制器无法重新注册的问题：`file-upload` 的 Agent 解析器改由普通对象持有，释放比较不再因 Cordis 服务代理每次返回新的函数包装而失效。
- 新增上游回归用例 `packages/client/file-upload/tests/file-upload-resolver-release.host.spec.ts`，锁定解析器释放与重复注册行为。
- 仓库统一使用 LF 换行：新增 `.gitattributes` 与仓库级换行守卫 `check-line-endings.sh`/`.ps1`，Windows 检出不再产生 CRLF，避免 `git apply` 与 NAS 运行时文件被破坏。

## 0.0.19

- 新增内置 `init` 技能，用于创建或增量更新项目的 AGENTS.md，保留用户已有内容。
- 技能随安装包分发，不复制或覆盖用户技能目录。

## 0.0.18

- 上游升级至 **DSH 0.2.1-rc.2**，包内 pnpm 更新至 11.28.5。
- 同步插件管理、Web 私有认证、附件权限边界与连接超时适配。
- 更新内置维护技能，修正安装路径、运行身份和技能加载方式说明。

## 0.0.17

- 调整连接心跳、就绪等待与 WebSocket 握手超时，改善慢连接下的稳定性。
- 改善变更摘要加载失败时的重试、取消与缓存行为。

## 0.0.16

## 0.0.15
