# Changelog

记录 fnOS 安装包的主要变化；安装包版本与上游 DSH 版本独立。完整技术细节与历史记录可通过 Git 历史追溯。

## Unreleased

## 0.0.20

- 修复插件配置热重载后会话控制器无法重新注册的问题：`file-upload` 的 Agent 解析器改由普通对象持有，释放比较不再因 Cordis 服务代理每次返回新的函数包装而失效。
- 新增上游回归用例 `packages/client/file-upload/tests/file-upload-resolver-release.host.spec.ts`，锁定解析器释放与重复注册行为。
- 仓库统一使用 LF 换行：新增 `.gitattributes` 与仓库级换行守卫 `check-line-endings.sh`/`.ps1`，Windows 检出不再产生 CRLF，避免 `git apply` 与 NAS 运行时文件被破坏。

## 0.0.19

- 新增内置 `init` 技能，用于创建或增量更新项目的 AGENTS.md，保留用户已有内容。
- 技能随安装包分发，不复制或覆盖用户技能目录。

## 0.0.18

- 上游升级至 **DSH 0.2.1-rc.2**，包内 pnpm 更新至 11.28.5。
- 同步插件管理、Web 私有认证、附件权限边界与连接超时适配。
- 更新内置维护技能，修正安装路径、运行身份和技能加载方式说明。

## 0.0.17

- 调整连接心跳、就绪等待与 WebSocket 握手超时，改善慢连接下的稳定性。
- 改善变更摘要加载失败时的重试、取消与缓存行为。

## 0.0.16

- 修复 WebSocket 升级后客户端首帧被重复转发的问题。

## 0.0.15

- 修复网关认证过期后持续返回 401 的问题，支持会话和令牌刷新。
- 修复 Session 导出认证及部分远程连接路径适配。

## 0.0.14

- 上游升级至 DSH 0.1.7-rc.1，精简本地补丁并接入上游插件管理器。
- 插件依赖使用 profile 私有存储，保留用户设置、会话与插件数据。

## 0.0.13

- 修复在 fnOS 文件管理器中打开文件时报“文件或文件夹不存在”的问题。
- 目录打开自身，文件定位到所在目录，Session 导出后打开导出目录。

## 0.0.12

- 修复侧栏文件树右键“在应用中打开”在 fnOS 中无反应的问题。

## 0.0.11

- 修复 fnOS Web 桥接初始化时序导致文件打开失败的问题。
- 降低当时的 TypeScript 构建内存上限。

## 0.0.10

- 恢复文件卡片的原生侧栏预览，移除 fnOS 适配对卡片点击的拦截。

## 0.0.9

- 修复旧版升级时，失效的运行时依赖软链导致安装回滚的问题。

## 0.0.8

- 修复 fnOS Web 桌面被误识别为移动端，导致文件打开持续等待的问题。
- 完善文件管理器适配，并统一 Linux 原生构建与校验流程。

## 0.0.6

- 修复升级或保留数据重装时，旧安装向导值覆盖当前 API Key、代理设置的问题。

## 0.0.5

- 内置 fnOS 维护技能与适配后的 `skill-creator`，不覆盖用户技能目录。

## 0.0.4

- 增加插件动态路由维护技能（后续版本已调整该机制）。

## 0.0.3

- 修复附件写入在 fnOS 卷权限边界失败及错误提示不准确的问题。

## 0.0.2

- 修复安装时创建系统 home 软链失败导致回滚的问题，改用 fnOS 应用目录。

## 0.0.1

- 应用标识重置为 `deepseek-harness`，开始独立的 fnOS 安装包版本系列。
- 移除旧版升级迁移逻辑，升级不改写用户 profile、设置与插件数据。
